# DSA Learning Roadmap

## Phase 1: Foundations (Weeks 1-4)

### Data Structures to Master
- [ ] **Arrays** — indexing, slicing, 2D arrays
- [ ] **Strings** — immutability, built-in methods
- [ ] **Hash Map / Hash Set** — O(1) average ops
- [ ] **Stack** — LIFO, call stack, expression evaluation
- [ ] **Queue / Deque** — FIFO, BFS, sliding window max

### Algorithms to Master
- [ ] **Two Pointers** — opposite ends, same direction
- [ ] **Sliding Window** — fixed and variable size
- [ ] **Prefix Sum** — range queries
- [ ] **Sorting** — understand all 8 algorithms
- [ ] **Binary Search** — classic, rotated, search on answer

### Problems: 40-50 Easy

---

## Phase 2: Core Data Structures (Weeks 5-8)

### Data Structures to Master
- [ ] **Linked List** — singly, doubly, dummy nodes
- [ ] **Tree** — traversals, height, BST operations
- [ ] **Heap / Priority Queue** — min/max, k-largest
- [ ] **Trie** — prefix tree, autocomplete

### Algorithms to Master
- [ ] **DFS / BFS** on trees and graphs
- [ ] **Recursion + Memoization** — top-down DP
- [ ] **Divide and Conquer** — merge sort, binary search

### Problems: 50-60 Medium

---

## Phase 3: Advanced Topics (Weeks 9-12)

### Data Structures to Master
- [ ] **Graph** — adjacency list, matrix
- [ ] **Union-Find** — path compression, union by rank
- [ ] **Segment Tree** — range queries and updates
- [ ] **Monotonic Stack/Queue**

### Algorithms to Master
- [ ] **Graph Algorithms** — BFS, DFS, Dijkstra, Bellman-Ford
- [ ] **Topological Sort** — Kahn's, DFS
- [ ] **Dynamic Programming** — 1D, 2D, interval, tree DP
- [ ] **Backtracking** — permutations, combinations, constraint satisfaction
- [ ] **Greedy** — activity selection, interval scheduling

### Problems: 40-50 Medium + 10-20 Hard

---

## Phase 4: Interview Preparation (Weeks 13-16)

- [ ] Mock interviews (3/week minimum)
- [ ] Time yourself (20 min easy, 40 min medium, 60 min hard)
- [ ] Review and optimize solutions
- [ ] System design basics
- [ ] Behavioral questions (STAR format)
- [ ] Company-specific preparation
