# 3-Month FAANG Interview Roadmap

## 📅 Month 1: Foundation

### Week 1 — Arrays & Hash Maps
**Daily:** 2 easy + 1 medium
- [ ] Two Sum, Contains Duplicate, Valid Anagram
- [ ] Group Anagrams, Top K Frequent, Product Except Self
- [ ] Longest Consecutive Sequence, LRU Cache
**Concepts:** Hash maps, frequency counting, prefix sums

### Week 2 — Two Pointers & Sliding Window
**Daily:** 1 easy + 2 medium
- [ ] Valid Palindrome, Two Sum II, Remove Duplicates
- [ ] 3Sum, Container With Most Water, Trapping Rain Water
- [ ] Longest Substring No Repeat, Min Window Substring
**Concepts:** Opposite-direction pointers, same-direction, variable window

### Week 3 — Stacks, Queues & Binary Search
**Daily:** 2 medium
- [ ] Valid Parentheses, Daily Temperatures, Largest Rectangle Histogram
- [ ] Binary Search, Search Rotated Array, Find Min Rotated
- [ ] Koko Bananas, Ship Packages (binary search on answer)
**Concepts:** Monotonic stack, binary search template

### Week 4 — Linked Lists & Recursion
**Daily:** 1 easy + 2 medium
- [ ] Reverse LL, Merge Sorted, Remove Nth, LL Cycle
- [ ] Reorder List, Palindrome LL, Copy List with Random
- [ ] Generate Parentheses, Merge Sort (recursion practice)
**Concepts:** Fast/slow pointers, dummy nodes, recursion patterns

---

## 📅 Month 2: Core DSA

### Week 5 — Trees (Part 1)
**Daily:** 2 medium
- [ ] Invert BT, Max Depth, Same Tree, Subtree
- [ ] Level Order BFS, Right Side View, Count Good Nodes
- [ ] LCA, Diameter, Path Sum II, Balanced BT
**Concepts:** DFS traversals, BFS level-order, tree properties

### Week 6 — Trees (Part 2) & BST
**Daily:** 2 medium + 1 hard
- [ ] Validate BST, Kth Smallest BST, BST Iterator
- [ ] Serialize/Deserialize, Max Path Sum (hard)
- [ ] Trie: Implement, Word Search II, Design Word Dictionary
**Concepts:** BST properties, inorder traversal, Trie structure

### Week 7 — Heaps & Priority Queues
**Daily:** 2 medium
- [ ] Kth Largest, K Closest Points, Task Scheduler
- [ ] Find Median from Stream, Sliding Window Maximum
- [ ] Merge K Sorted Lists, Top K Frequent Words
**Concepts:** Min/max heap, two-heap pattern

### Week 8 — Graphs
**Daily:** 2 medium + 1 hard
- [ ] Number of Islands, Clone Graph, Flood Fill
- [ ] Course Schedule I/II, Number of Connected Components
- [ ] Word Ladder (BFS hard), Network Delay Time (Dijkstra)
**Concepts:** BFS/DFS on grid/graph, Union-Find, Topological Sort

---

## 📅 Month 3: Advanced Topics

### Week 9 — Dynamic Programming (1D)
**Daily:** 2 medium
- [ ] Climbing Stairs, House Robber I/II, Coin Change
- [ ] Maximum Product Subarray, Word Break, Decode Ways
- [ ] LIS (binary search approach), Jump Game I/II
**Concepts:** 1D DP, space optimization, DP to greedy

### Week 10 — Dynamic Programming (2D)
**Daily:** 1 medium + 1 hard
- [ ] Unique Paths, LCS, Edit Distance, Palindrome Substrings
- [ ] Distinct Subsequences, Interleaving String (hard)
- [ ] 0/1 Knapsack, Burst Balloons (hard), Coin Change Ways
**Concepts:** 2D DP tables, interval DP

### Week 11 — Backtracking & Greedy
**Daily:** 2 medium
- [ ] Subsets, Permutations, Combination Sum I/II
- [ ] N-Queens, Sudoku Solver (hard), Word Search
- [ ] Merge Intervals, Non-overlapping Intervals, Partition Labels
**Concepts:** Backtracking template with pruning, greedy proofs

### Week 12 — Mock Interviews & Review
- [ ] 3 mock interviews per week
- [ ] Review weak areas
- [ ] System design basics
- [ ] Behavioral questions (STAR method)
- [ ] Review top 50 problems quickly

## 🏢 Company Focus

### Meta (Facebook)
- Focus: Arrays, Strings, Trees, Graphs, Dynamic Programming
- Style: 2 coding rounds, clean optimal solution expected
- Top: BFS/DFS, sliding window, tree traversals

### Google  
- Focus: All topics + scalability
- Style: Multiple solutions, trade-offs discussion
- Top: Graph algorithms, DP, system design

### Amazon
- Focus: Arrays, Trees, Graphs, OOP + Leadership Principles
- Style: Behavioral (STAR) + coding
- Top: BFS, two pointers, design patterns

### Microsoft
- Focus: Arrays, Strings, Trees
- Style: Clear communication, thought process
- Top: String manipulation, BST, DP

### Apple
- Focus: Clean code, OOP, algorithms
- Style: Real-world application focus
- Top: Arrays, strings, design patterns
